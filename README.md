# VanillaBonds — public site

Static site for vanillabonds.com (GitHub Pages).

- `index.html` — landing page: the full story (gap, why now, platform, format, credit filter, investors/issuers, process, Monitor, roadmap)
- `demo.html` — platform demonstration (fictitious data), dark terminal styling, four views: Deal Journey (scroll-driven issuance story, default), Market, New Issues, Pricing (`#journey` / `#market` / `#issue` / `#pricing` deep-link)
- `pricing.html` — redirect stub → `demo.html#pricing` (tool moved into the demo; kept so old links don't break)
